# Contributing

Thanks for your interest in improving Bottle Conformity Test.

## Before contributing

- Open an issue to discuss substantial changes before starting work.
- Keep changes focused and preserve the existing notebook workflows.
- Do not submit credentials, private production data, or images/model weights
  without documented redistribution rights.
- Do not describe this prototype as certified or production-safe.

## Pull requests

1. Explain the problem and the intended change.
2. Include steps to reproduce and verify the change.
3. Keep notebook outputs free of local paths, camera details, and private data.
4. Update the README or other documentation when behavior or setup changes.
5. Identify any changes to model, dataset, dependency, or license terms.

There is no automated test suite at present. State clearly which checks were
run and which could not be run because they require a webcam, GPU, dataset, or
model weights.
