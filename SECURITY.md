# Security Policy

This project is an experimental computer-vision prototype and is not
security-certified or suitable as the sole control in an industrial
inspection process.

## Reporting a vulnerability

Please do not publish exploit details, credentials, or private images in a
public issue. Once GitHub private vulnerability reporting is enabled for the
public repository, use that channel. If it is unavailable, contact the
maintainer through the GitHub account associated with this project and avoid
public disclosure until a fix or mitigation can be coordinated.

Reports should include the affected file or dependency, the impact, and
reproduction steps that do not expose real user or production data.

## Supported versions

No formal release versions or security support window have been established.
